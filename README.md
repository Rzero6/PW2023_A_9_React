# 🚘 Car Rental Web App — Frontend

A web-based car rental platform where users can browse available cars, make rental transactions, manage profiles, and view rental history. Built with **React (Vite)** and connected to a custom **Laravel API** backend.

---

## 🛠️ Tech Stack
- **React + Vite**
- **JavaScript**
- **Material UI & Bootstrap**
- **Axios**
- **React Router**

---

## ✨ Features
- 🔐 Login / Register
- 🚗 Search available cars
- 💳 Make rental transactions
- 📜 View rental history
- 👤 Profile update

---

## 🔌 Backend Integration
This frontend communicates with the following API:
👉 [*Laravel Car Rental API*](https://github.com/Rzero6/PW2023_A_9_Laravel) (Authentication with Laravel Passport)

---

## ▶️ How to Run Locally
```bash
npm install
npm run dev
```
